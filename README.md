# Die Bibliothek der Zeiten

Familien-Rollenspiel mit Begleit-App. Alles, was Claude Code braucht, liegt in diesem Ordner.

## So startest du in Claude Code

1. Entpacke den Ordner `bibliothek-der-zeiten` auf deinem Rechner.
2. Öffne den Ordner in Claude Code.
3. Schreibe als erste Nachricht:

   > Lies CLAUDE.md und docs/app-spec.md. Baue die erste Version des Spielleiter-Walkthroughs laut Ausbaustufe 1 und zeig mir danach, wie ich sie auf dem Handy öffne.

## Befehle für den Spielabend

| Befehl | Wofür |
| --- | --- |
| `/spielabend a1` | Co-Spielleiter für einen ganzen Abend |
| `/raetsel Pyramide Mathe` | Neues Rätsel in Klasse 1 und 2 |
| `/wendung …` | Die Helden tun etwas Unerwartetes |
| `/figur Bäcker im Römerlager` | Spontane Nebenfigur |
| `/abenteuer-neu Tiefsee` | Nächstes Abenteuer im gleichen Format |

## Noch offen

- Musik und Geräusche: Dateien laut `docs/medien.md` nach `assets/musik/` und `assets/sounds/` legen.
- Bilder: Artboards aus dem Canvas als PNG nach `assets/bilder/` exportieren, oder Claude Code aus `assets/quelle/` erzeugen lassen.
