# Spielleiter-Spickzettel

## Die Welt in vier Sätzen

Hinter einer knarzenden Tür liegt die Bibliothek der Zeiten. Jedes Buch ist ein Portal in eine Epoche, man ruft „Lies mich, nimm mich mit!“. Professorin Eulalia, eine Schleiereule, ist die Bibliothekarin, Krümel ihr Baby-Bücherdrache. Die eitle Elster Gräfin Glitzer klaut glänzende Seiten, und die Helden holen sie zurück.

## Ablauf eines Abends (45 Minuten)

1. Ankommen und Herzen auffüllen, 3 Minuten. Jeder sagt seinen Heldennamen in Heldenstimme.
2. Rückblick, 2 Minuten. Die Tochter erzählt, was letztes Mal passiert ist. Dafür gibt es einen Glücksstern. Am allerersten Abend spielt ihr stattdessen die Übungsszene aus `data/abenteuer/a0-uebung.json`, 10 Minuten.
3. Drei Szenen, je 10–15 Minuten, laut Abenteuer-Datei.
4. Abschluss, 5 Minuten. Stempel verteilen, jeder nennt seinen liebsten Moment.

## Regeln auf einen Blick

| Was | Regel |
| --- | --- |
| Probe | So viele W6 wie Punkte, der höchste zählt |
| Schwierigkeit | Leicht 4+, schwer 5+, episch 6 |
| Volltreffer | Jede 6: klappt plus Bonus, der Spieler bestimmt mit |
| Talent / Helfen | Je +1 Würfel |
| Glücksstern | +2 Würfel, für jedes gelöste Rätsel |
| Kampf | Helden zuerst, Gegner würfeln nie, Ausweichen mit Geschick |
| 0 Herzen | Erschöpft, Aufmuntern mit Herz 4+ |
| Krümel | 1× pro Abenteuer Plüschwürfel, beim Höhepunkt: 4–6 = alle +1 Würfel |

## Stimmen der Figuren

- **Eulalia:** hoch, schnell, verwechselt Wörter. Tippt sich an die Nase (Brille hochschieben).
- **Gräfin Glitzer:** eingebildet, lange Vokale: „Daaas ist MEIN Schaaatz!“
- **Gaius, Karl, Rostig:** brummig, langsam, gutmütig. Karl kaut, Rostig quietscht.
- **Krähen:** Alle Erwachsenen krächzen mit.

## Spotlight-Regeln

- Rätsel gehen zuerst an die Tochter. Erwachsene helfen nur, wenn sie fragt.
- Jede Szene hat einen Moment, in dem ihr Held glänzt. Vorher einplanen.
- Erwachsene kürzen keine Kinder-Rätsel ab: keine Schlösser, kein Flunkern, kein Kristall vor dem Lösungsversuch.
- Krümel bekommt pro Abenteuer einen Wurf, beim Höhepunkt in Szene 3.

## Improvisieren

- **Ja, und …** Jede Idee annehmen und darauf aufbauen.
- **Scheitern ist lustig.** Ein Fehlschlag bringt einen Hinweis, eine Figur oder einen Lacher.
- **Hängen geblieben?** Eulalia ruft einen Tipp aus dem Buch, oder die Krähen stören.
- **Zu lang?** Kampf auf eine Runde kürzen. Plan B steht in jedem Abenteuer.
